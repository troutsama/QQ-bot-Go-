## 三、下一步开发清单（M1 收尾 ➔ M3 核心）

1. **实现数据库迁移引擎（`store.Migrate`）**
   - 在 `internal/store/migrate.go` 中，使用 `//go:embed migrations/*.sql` 读取 `0001_init.sql`。
   - 使用 SQLite 内置的 `PRAGMA user_version` 实现事务级安全迁移。
2. **实现会话与轮次读写（`internal/store/`）**
   - `conversation.go`：实现 `GetOrCreateConversation`（按 `app_id + scene + scene_id` 获取或创建会话）。
   - `turn.go`：实现 `BeginTurn`（事务内创建轮次并写入首条用户消息，支持 `UNIQUE` 幂等防重推）。
   - `turn.go`：实现 `RecentTurns`（读取最近 N 轮 `status = 'ok'` 的有效上下文记录）。
   - `turn.go`：实现 `FinishTurn`（回写模型请求结果、Token 消耗并标记 `ok`）。
3. **实现模型调用记录落地（`llm_requests`）**
   - 实现 `RecordLLMRequest`：将完整请求入参与响应 JSON 快照写入 `llm_requests` 表，并反写 `turn.llm_request_id`。
