# NapCat → QQ 官方 Bot（Go 版）改造文档

> **这是什么**：把现有 TypeScript 版 `napcat-platform` 改造为「QQ 官方机器人 + Go」的设计文档集。
> **给谁看**：作者本人（学 Go，手写代码为主）+ 后续加入的学弟。
> **在哪**：本文档目录是**跨仓库设计约定**；Go 代码在另一个独立仓库里（见 §5）。

---

## 一、3 分钟上手

| 你现在的处境 | 按这个顺序看 |
|-------------|-------------|
| **第一次读**，想知道这项目要做什么 | `01` 的第一部分（§1.x）→ 回来读本文档 §4 的开放问题 |
| **准备动手写 V1 代码** | `01` §8（目录演进 + 缝清单）→ `02`（架构与接口）→ `06`（V1 编码指南）→ `07`（V1 实施计划） |
| **动手前最后一遍** | `04` 的 §6.1 风险清单（**至少扫一遍**） |
| **写到某个包不知道怎么写** | `06` 对应章节（逐包 demo + Go 新手须知） |
| **不知道这轮要做到什么程度** | `01` §8.3（L1/L2/L3 深度刻度） |
| **要加 V2/V2.5/V3 功能** | `01` §1.2（迭代边界）→ `08` |
| **翻旧 TS 实现怎么对应** | `05` |
| **不确定某处会不会踩坑** | `04` |

**一句话路线**：先走到「mock 全链路能 curl 跑通」（`07` 的 M5 里程碑），再接真实 QQ 与模型。这样你永远有一半是假的，**永远测得起**。

| 文档 | 用途 | 什么时候读 |
|------|------|-----------|
| `01` | 定了「做什么、不做什么、每轮做到什么程度、目录怎么长」 | 开工前 + 每次进入新迭代 |
| `02` | 定了「代码放哪、谁能依赖谁、接口长什么样」 | 写代码前；review 自己的代码时 |
| `03` | 定了「表怎么建、配置怎么写、API 有哪些」 | 写 `store`/`config`/`admin` 时查 |
| `04` | 定了「哪里会翻车、为什么这么选」 | 动手前必扫；遇到诡异 bug 时 |

## 四、需要你确认/填写的参数

文档以下内容按**推荐值**书写，若与你的实际选择不同，全局替换即可。

| 参数 | 推荐值 | 影响范围 |
|------|--------|----------|
| module 名 | `qqbot` | 所有 Go 文件的 import 行 |
| 仓库目录名 | `qq-bot-go` | 与 module 名无需一致，Go 不要求 |
| 二进制名 | `botd` | `cmd/botd/`、`Makefile` |
| QQ SDK | `github.com/tencent-connect/botgo`（你已测通） | §3.x 的适配器映射 |

### 三个开放问题（答案会影响文档准确性）

| # | 问题 | 当前假设 | 影响 |
|---|------|----------|------|
| Q1 | 「两种 OpenAI 格式」指哪两种？ | `/chat/completions` + `/responses` | §3.3 适配器数量与字段映射。**若你其实是指「OpenAI 原生 + 第三方兼容（DeepSeek/通义）」，则第 2、3 个适配器应合并成一个** |
| Q2 | 单条消息 `content` 的真实长度上限？ | 未确认（暂用 1500） | `segment_max_chars` 默认值（§4.4、T2） |
| Q3 | `msg_type=6`（输入中）是否消耗被动回复次数？ | 未确认（默认关闭） | 能否默认开「输入中」反馈（§5.3、T3） |

## 五、把文档放进 Go 仓库

```bash
# 1) 设计文档
mkdir -p ~/code/qq-bot-go/docs/design
cp "napcatQQ/go 改造"/*.md ~/code/qq-bot-go/docs/design/

# 2) 让 AI「只讲解不代写」的配置（AGENTS.md + .pi + 技能）
cp -R "napcatQQ/go 改造/go项目待置入/." ~/code/qq-bot-go/
```

`go项目待置入/` 的四层防护与验证方式见 `go项目待置入/README.md`。核心是 `.pi/settings.json` 把 `edit`/`write`/`bash` 从工具列表里**物理移除** —— 不是「让它别写」，而是「它做不到」。
