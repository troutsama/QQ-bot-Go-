# V1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **本项目是「学习模式」**：`AGENTS.md` 规定 agent 只讲解、不代写代码。若由你自己执行本计划，按 checkbox 逐个走；若由 agent 执行，需先按 `go项目待置入/README.md` §8 显式解锁。

**Goal:** 让 Go 版服务能真实收/发 QQ 官方 Bot 单聊消息、调用模型、按最近 10 轮有效对话拼接上下文并分段回复，同时提供 API-only 的运维面（日志/配置/重载/重连/重启）。

**Architecture:** 端口/适配器 + 显式组装。`chat` 是业务核心（只依赖接口），QQ 平台与模型协议都是可替换适配器，所有对象在 `cmd/botd/main.go` 一处创建，全项目无全局单例。

**Tech Stack:** Go 1.22+ · `net/http` · `log/slog` · `embed` · `github.com/tencent-connect/botgo`（WS 接收 + v2 单聊发送）· `modernc.org/sqlite`（纯 Go）· `gopkg.in/yaml.v3` · `gopkg.in/natefinch/lumberjack.v2`

**Spec:** `docs/design/01-总览.md` ~ `docs/design/08-V2V3-编码指南.md`（其中 `03` 定接口、`04` 定表结构与上下文算法、`05` 定配置与运维面、`09`/`10` 给逐包示范与 Go 新手须知、`11` 给 V2+ 增量）

## Global Constraints

- Go **1.22+**（`net/http` 方法路由、`errors.Join`、`slices` 包）
- 依赖仅允许：`botgo`、`modernc.org/sqlite`、`yaml.v3`、`lumberjack.v2`；其余一律标准库
- **不引入** Web 框架 / ORM / DI 库 / 配置库（viper）/ 日志库（logrus、zap）
- 接口**定义在使用方**；`internal/chat/` 内**不得**出现 `botgo` 或 `openai` 字样
- 依赖方向：`provider/* → port ← chat`；`store → chat`（适配器依赖核心，核心不感知适配器）
- **不用全局单例**（禁止 `sync.Once` + `panic` 做容器）；依赖显式注入
- 工厂 = 组合根里的显式 `switch`，**不用 `init()` 注册表**
- SQL **只**出现在 `internal/store/`
- 字符长度一律 `utf8.RuneCountInString` / `[]rune`，**禁止用 `len()` 数字符**
- DB 时间存 **Unix 毫秒**；显示用配置 `chat.timezone`，**禁止 `time.Local`**
- 错误用 `fmt.Errorf("...: %w", err)` 包装；跨层用哨兵错误 + `errors.Is`
- 日志用 `log/slog`；业务事件写 `events` 表（`logx` 只负责运行日志）
- 单测**不连 QQ、不调真实模型**
- 新增/变更配置项必须同步 `config.example.yaml`
- 迁移**只追加**；禁止修改已发布的迁移文件
- 提交信息前缀：`feat:` / `fix:` / `chore:` / `test:` / `docs:`

## Review Focus

以下 6 类输入/故障，规格隐含要求但没有任何单个任务天然覆盖，最可能让使用者踩坑。**每一行都在下面标了归属任务，并在该任务里补了对应测试。**

1. **同一条入站消息被重复推送**（含 WS resume 后重推）→ 只处理一次；若库里那一轮 `finished_at IS NULL` 则**接管重试**而不是跳过（R2、R15）→ T16
2. **同一会话连发多条消息** → 严格按顺序处理，上下文不串、回复与问题一一对应（R3）→ T15、T16
3. **模型返回超长回复** → 段数 ≤ `max_reply_segments`，无重复内容、不切断多字节字符（R1）→ T10
4. **用户发非文本消息**（图片/语音）→ **不调用模型**、回固定提示、该轮记 `filtered`（R13）→ T16
5. **模型调用失败**（401 / 429 / 超时）→ 用户看到可读中文文案；该轮**不进上下文**；日志含 trace_id 与原始错误（R16、错误分类）→ T16、T23
6. **服务器时区不是 Asia/Shanghai** → 历史消息时间前缀仍按配置时区渲染（R20）→ T11
